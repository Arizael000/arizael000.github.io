# 🎨 Visual Standards & Consistency Guide
Este módulo asegura que todos los componentes mantengan la coherencia estética con la marca y el diseño general del portafolio.

## 🌈 Paleta de Colores
Toda la paleta debe ser respetada:
*   **Primario:** [Código HEX] - Usado para elementos principales (botones primarios, encabezados).
*   **Secundario:** [Código HEX] - Usado para soporte visual y diferenciación.
*   **Acento/Éxito:** [Código HEX] - Reservado para CTAs o estados positivos de éxito.
*   **Texto Base:** [Color Gris Oscuro] - Para el cuerpo del texto principal (alto contraste).

## 🔡 Tipografía
Se debe usar estrictamente la combinación tipográfica definida:
*   **Fuente Principal (Headers):** 'Inter', sans-serif.
*   **Fuente Cuerpo de Texto:** 'Roboto', serif, o según la definición global.
* **Regla:** La jerarquía visual se establecerá por el tamaño y peso, no solo por el color.

## 📐 Espaciado y Patrones
Se debe mantener un sistema de espaciado basado en unidades relativas (ej: `rem` o porcentajes) para garantizar la consistencia en márgenes, paddings y tamaños de fuente a través de todos los componentes.
